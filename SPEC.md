# IC-Lib SPEC

## §G

G1: manage PCB/OrCAD component lib end-to-end: vendor intake -> CAD asset control -> approval/status control -> inventory/project/BOM reuse.
G2: keep app operable on fresh or drifted DB via startup init, numeric migrations, auth bootstrap, file scan/repair, email/runtime config.
G3: provide audit/reporting/admin surfaces for governed library ops.

## §C

C1: stack React 19 + Vite + TailwindCSS v4 + React Query 5 | Express 4 | PostgreSQL 18 | JWT cookie auth.
C2: DB primary keys ! `UUID DEFAULT uuidv7()`; create time derive via `created_at(id)`.
C3: app owns flat CAD tree `library/footprint|symbol|model|pspice|pad` + temp/delete buffers; DB tracks `cad_files` + `component_cad_files`, plus `footprint_related_cad_files` for reusable footprint-driven pad and 3D-model history.
C4: views `components_full`, `component_specifications_view`, `eco_orders_full`, `production_parts`, `prototype_parts`, `archived_parts`, `alternative_parts` = external OrCAD-CIS/ODBC compat surface only — server runtime ⊥ query them; keep + startup-verify all 7 (`EXPECTED_SCHEMA_VIEWS`, locked by `schemaInspectionService.test.js`); OrCAD/CIS compat ! keep TEXT cols `pcb_footprint|schematic|step_model|pspice|pad_file`. note: live `schema_migrations` holds historical row `0_schema_version_1_8_0.sql` (file ∉ repo) — inert, pending-detection = files minus rows; ⊥ delete history. note: `footprint_sources` table legacy — 0 rows live, ∄ writer (footprint fetch stages via `library/temp` instead); kept in schema/backup/clear lists, ⊥ new writes.
C5: roles `read-only|reviewer|lab|read-write|approver|admin`; `lab` = `read-write` except File Library page/browse/manage access ⊥; some component-scoped CAD helper APIs still usable from Parts Library edit flow.
C6: runtime flags/env ! support `CONFIG_ECO`, `CONFIG_BASE_URL`, `CONFIG_SUBDIRECTORY_PATH`, DB creds, vendor API creds, `SMTP_ENCRYPTION_KEY`.
C7: startup may repair missing base schema from `database/init-*.sql`; incremental change ! live in `database/migrations/<int>_<desc>.sql`.
C8: file ops & import/repair flows must work on shared repo filesystem; path escape ⊥.
C9: spec target code-as-built first; known drift/bugs record in `§B`, not hidden.
C10: flexible workflow/audit payloads may persist in JSONB: `activity_log.details`, distributor `price_breaks`, ECO alt `distributors`, similar variable-shape data.

## §U

U.roles: 6 roles `read-only|reviewer|lab|read-write|approver|admin`. `/login` = normal sign-in + guest read-only sign-in + `Sign in with {provider}` button when OIDC on (`GET /api/auth/oidc/status`); SSO callback error -> `/login?error=sso_failed|account_disabled` banner; success -> requested route if any.
U.land: `read-only|reviewer` -> `/eco` if ECO on else `/library`; `lab|read-write|approver|admin` -> `/`.
U.nav: `read-only` = Library, ECO; `reviewer` = +User Settings; `lab|read-write|approver|admin` = Dashboard, Library, Inventory, Vendor Search, Projects, Reports, Audit, User Settings; `read-write|approver|admin` = +File Library; `admin` = +Admin Settings. ECO route/nav only when flag on. Sidebar: collapse + dark mode persist localStorage; show version, user card, logout.
U.model: most screens = left filter/nav pane + right detail pane; write flows in modals; toasts carry save/import/update progress. Pivots: Library <-> Inventory|Projects|Vendor Search|File Library(role), Inventory -> Library|Vendor Search, File Library -> Library, Vendor Search -> Library, Projects BOM settings -> Admin BOM, User file-path -> File Library copy-path, Admin scan -> File Library new-file visibility.
U.dash `/`: full-nav roles. DB not init -> warn + push admin to settings. Totals lib|categories|manufacturers|projects|distributors; approval-state counts, stock counts, category distribution, DB info, CAD-health.
U.lib `/library`: browse + detail + add/edit + ECO + CAD + push-to-project.
- browse: category sidebar, full-text search, sort PN|MFG P/N|value|desc|created|updated, multi-status filter, prev/next step when search parses as PN, virtualized list, copy deep link. view prefs persist: sort/order/status-filter/category -> localStorage `viewPrefs:library` (whitelist-validated via `client/src/utils/viewPrefs.js`; corrupt|unknown -> defaults; stale category id -> reset ''), search term -> per-tab sessionStorage ∴ add-part round-trip returns to same view.
- detail: copyable fields, alt selector, datasheet link, CAD links -> File Library deep links only for File-Library roles (`lab` sees plain filenames), approval status/history, assigned-project tile (click -> Projects), pivots Inventory|Add-to-Project|File Library(role), distributor panel -> Vendor Search, read-only specs.
- add/edit: manual fields, category numbering/template, manufacturer typeahead + create-new, package + sub-category suggest, spec editor + custom spec + vendor-field mapping, alt editor + promote/delete + distributor rows, CAD manager (schematic|footprint|pad|3D|PSpice), upload files or ZIP, staged `.olb` -> two-panel assignment popup (first `.olb` defaults schematic, may move to PSpice before save), link existing files, linking footprint auto-adds known pad+3D from history, rename shortcuts (freeform|MFG P/N|package), footprint pairs move together, save-time conflict modal `use_existing|overwrite`.
- vendor-assisted: Vendor Search opens add mode w/ prefilled payload; vendor panel copy + `Auto Fill` (base fields + mapped specs); mapping modal binds vendor field -> spec or new custom spec.
- direct edit: ECO off -> write roles edit live + bulk-delete; ECO on -> admin edit any, non-admin write edit `new` parts only.
- ECO: write roles `Initiate ECO` (`new` part only when ready to propose `prototype`); stage field/spec/distributor/alt/CAD/status/delete + notes; status proposals per §V21; no path back to `new`; retry reload rejected change-set under same ECO chain; ECO blocks live-file overwrite.
U.vendor `/vendor-search`: find distributor data, seed part, append rows, add alts. text search PN|MFG P/N; vendor scan panel (same shared decoder/panel as U.inv, inline variant): decode ok -> search box = MFG P/N|SKU + auto vendor search; decode error -> panel error, raw ECIA ⊥ search box. side-by-side Digikey+Mouser panes, multi-select cross-vendor, sessionStorage keeps results+selection. Actions: `Add to Library` -> prefilled draft (one source primary, all selections -> distributor rows); `Append to Existing Parts` -> exact MFG P/N match -> target primary|alt; no match -> modal target other part as new alt or fall back to new-part; download footprints Ultra Librarian|SnapEDA.
U.eco `/eco`: review change orders, inspect staged, act, export PDF. status buckets pending|in_review|approved|rejected; filters part|ECO number|initiator|pipeline tags; expand -> lazy full detail; eligible approvers comment/approve/reject w/ reason; any auth ECO-visible user inspects; per-ECO PDF; current-stage actability respects explicit approver assignment + delegation.
U.file `/file-library`: browse shared CAD, inspect reuse, rename, copy paths, clean orphans, CIS downloads. access `read-write|approver|admin`; `lab` keeps part-scoped picker in Library edit, ⊥ this page. modes: `File Types`(schematic|footprint|pad|3D|PSpice) + `Category`(category->component->files).
- File Types: type counts, global search, filter all|orphans, copy-path uses per-user storage path (User Settings), PSpice section holds `.lib` libs + PSpice `.olb` symbols w/ per-file lib-vs-symbol labels, selected file -> linked components + Library links, footprint/pad/3D header shows linked counterparts from history, footprint pairs grouped, admin footprint header `Edit Pad Link`/`Edit 3D Model Link` next to `Rename` (popup add/remove links), rename/delete permission-gated, orphan-only multi-select delete, CIS template/config downloads in sidebar.
- shared rename: ECO on + non-admin + affected parts > 1 + ≥1 non-`new` -> shared transparent-gray warning modal -> 1 mass ECO `Shared Rename` tag -> push only non-`new` affected -> `reviewing`, keep `new` editable, apply rename after approval; admin direct rename even ECO on (see §V20).
- Category mode: category list -> component list -> selected-part CAD + sharing info, rename + copy-path per file, same shared-rename rules (skip `new`), Library links for part + sharing parts.
U.inv `/inventory`: locate stock, adjust qty/min, scan labels, copy QR, pivot Library|Vendor Search. filters category|project|approval|location; full-text across part + alt fields (200ms debounce); sort PN|MFG P/N|qty|location|min|last-edited (persists localStorage `viewPrefs:inventory`, whitelist-validated); vendor scan panel `VendorBarcodeScanPanel` (shared decoder `client/src/utils/vendorBarcode.js`, Enter/Tab terminator -> instant decode, 250ms fallback debounce, camera modal; keystrokes re-render panel only; raw ECIA ⊥ leave panel); low-stock card; label-template download. table: expand -> alts; read mode location/qty/min/Library jump/label; edit-all -> bulk location, direct qty set, consume, receive, min updates (primary + alt); QR/label modal + copy. scan decode -> search = MFG P/N|SKU; filtered view 0 rows -> exact server lookup `POST /api/inventory/search/barcode` (di.sku|MFG P/N|PN) -> hit hidden by filters -> clear-filters CTA | no hit -> Vendor Search CTA.
U.proj `/projects`: manage BOM, allocate, consume, export. create/edit/delete; status active|completed|archived; select -> description + component list; rows show lowest-break unit price + extended line total when distributor pricing ∃, header rolled-up priced total + flags missing pricing; PN in list -> Library pre-filtered+selected; add by search or bulk pasted MFG P/N; set per-project qty; remove parts; `Consume All` -> decrement whole project; `Generate BOM` -> column-picker modal (admin defaults) -> CSV; export enriches rows w/ live component+distributor+alt data (see §V17, `client/src/utils/bomExport.js`).
U.reports `/reports`: pick type sidebar -> live data + CSV. set: Library Quality, CAD Coverage By Category, Category Distribution, Estimated Inventory Value, Footprint Issues, Manufacturer Coverage, Low Stock.
U.audit `/audit`: filter search|activity type|date range|page size; expand row -> JSON details; export filtered CSV; pagination.
U.user `/user-settings`: account summary username/role/sign-in method (local|SSO); profile display name/email/file storage path; ECO notification prefs; delegated backup approver; password change (local only — SSO accounts see IdP-managed note, ⊥ form).
U.admin `/admin-settings` tabs:
- User: create/edit/activate/deactivate/delete, change role incl `lab` + optional password, export/import user JSON.
- BOM: default BOM export columns.
- Category: create categories, edit prefix/leading-zeros/name, global prefix rules, reorder, manage category specs, rename/merge manufacturers.
- ECO: ECO number prefix + next seq, manage approval stages/order/parallel groups/required roles/required approvals/stage tags incl `Shared Rename`/assigned approvers, export/import stages JSON, PDF branding + doc-control notify email.
- Email: SMTP host/port/auth/from/TLS, test connection, send test email, preview ECO templates.
- Update: bulk stock refresh + bulk spec refresh (oldest sync first, skipped advance queue, daily-limit abort; see §V24), bulk distributor fill, scan library folder for untracked CAD.
- Operation: verify schema, init defaults (settings/categories/distributors/specs/ECO), export/import compressed DB backups, destructive full reset/delete parts|project data/delete users.
- Logs: clear audit log after confirm.
U.paths: end-to-end:
- vendor-assisted new part: Vendor Search/scan -> multi-select -> send to Library -> review category/numbering/specs/distributors/alts/CAD -> save or later ECO.
- manual new part: Library -> add manual -> category + required fields -> specs/CAD/alts -> save (inventory row created/repaired).
- controlled change: open saved part -> start ECO -> stage changes -> submit w/ notes -> review+act in ECO -> if rejected reload change-set + resubmit.
- shared file governance: link/upload in Library -> File Library inspect reuse/rename/orphans/copy paths -> admin library scan when disk has unregistered files.
- stock->BOM: maintain Inventory qty -> build projects from saved parts -> adjust/bulk import MFG P/N -> consume -> export BOM w/ chosen columns.
U.rules: guest login = first-class read-only; limited roles ⊥ Dashboard/File Library/Inventory/Projects/Reports/Audit nav; ECO visibility feature-flagged; CAD uploads stage before save (delete/replace reversible till save/cancel); footprint pairs grouped across upload/rename/file-library; add/edit conflict modal reuse-existing|overwrite; ECO mode ⊥ live-file overwrite; ECO shared non-admin rename -> warning modal -> staged approval before filename change; admin shared rename direct; file-path copy depends on per-user storage base; BOM export defaults from admin but user-selectable per export; approval-stage assignees narrow action to named users; delegation allows backup action.
