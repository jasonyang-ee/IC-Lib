I want to add a alternative rating system. This will rate Class A, B, C; A being cannot replace unless direct approval; B being can replace with following drawing notes; C being can replace with following just components value. This is a system for evaluating the criticality of components in a design or assembly. Mostly applied for passive components, this rating system helps to speed up PCB build process to allow using generic resistor or capacitor when the original specified part is not available, while still maintaining the integrity of the design.
